# cards-article

Custom **cards** block. Purpose: Grid of article/adventure teasers: image, title, one-line description, each linking to a detail page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: image | body (title, description, link); with category-filter-tabs, an optional trailing cell lists categories (comma-separated).

## Supported variations

| Variation | Option class |
| --- | --- |
| Category Filter Tabs | `category-filter-tabs` |
