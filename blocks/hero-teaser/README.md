# hero-teaser

Custom **hero** block. Purpose: Promotes one item with image, title, description and CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image (own row or cell) + text (optional eyebrow paragraph, heading, description, CTA link).

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Beside Text Panel | `image-beside-text-panel` |
| Image Bottom (crop the image from its bottom edge) | `image-bottom` |
