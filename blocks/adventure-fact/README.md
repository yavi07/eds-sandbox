# adventure-fact

Custom **custom** block. Purpose: Label/value trip fact (e.g. Activity: Rock Climbing) in the adventure details sidebar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per fact: label | value; a single cell is read as first paragraph = label, rest = value.
